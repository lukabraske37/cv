# CV — Luka Brašanac

Moj lični CV/resume, kao statičan sajt (živi dizajn) plus PDF verzije za slanje.

## Fajlovi

- `index.html` / `cv-luka_5.html` — dizajnirana verzija CV-a (web prikaz)
- `cv-ats.html` — čist, ATS-friendly HTML format za sisteme za skrining CV-jeva
- `LukaBrašanac-CV.pdf` — PDF verzija za slanje na konkurse
- `LukaBrasanac-CV-ATS.pdf` — ATS-safe PDF (bez grafike, čist tekst)

Održava se lokalno u `cv-main` folderu i push-uje ovde.
